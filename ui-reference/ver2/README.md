# 冰箱小精灵 ver2 · UI 参考预览（ESP32-P4 · 横/竖双模式）

本目录是「冰箱小精灵」下一代设备 UI 的**网页参考预览**，完整实现 `doc/` 规划文档定义的
**30 个页面模板 + 12 个全局浮层 + 8 种状态侧舱情境（CTX）**，供设计走查与固件 LVGL
实现对照使用。

- 目标设备：慧勤智远 ESP32-P4 CB V1.2 + 7 寸 1024×600 MIPI-DSI 横屏 + GT911 触摸
- **双模式外壳**（同一套页面/浮层，仅外壳重排）：
  - **横屏标准** `1024×600`：主区 704 | 导航 72 | 状态舱 248（摄像头可用）
  - **竖屏隐私** `600×1024`：上主区 672 / 中导航 64 / 下状态舱 288（**绑定隐私模式，摄像头关闭**；底舱为顶状态条 + 紧凑 CTX）
- 固件 GUI：LVGL 9.2.2（RGB565），字库角色 18/22/28/36/48/64（TF 卡字体包 + FreeType 回退）
- 权威输入：`doc/冰箱小精灵_ESP32-P4_LVGL页面架构与交互规划_V1.0.md`、
  `doc/冰箱小精灵_UI页面路由与状态清单_V1.0.json`、`doc/冰箱小精灵_页面样式设计交接提示词_V1.0.md`
- 视觉风格：暖色 + 鼠尾草绿（延续 ver1 调色板；布局为 ver2 全新三栏壳，与 ver1 方屏无关）
- Web 运维面板：侧栏 **UI 预览** 可 iframe 嵌入本目录，并切换横/竖（Vite 路径 `/ui-ver2/`）

## 一、打开方式

**直接双击 `index.html`** 即可（零依赖：无构建、无 ES Module、无 fetch、无 CDN、无网络字体，
`file://` 下完全可用）。也可以起本地服务：

```bash
cd ui-reference/ver2
python -m http.server 8000     # 然后访问 http://localhost:8000
```

或从项目 Web 面板进入：

```bash
cd web
npm run dev
# 浏览器打开面板 → 侧栏「UI 预览」→ 切换「横屏标准 / 竖屏隐私」
```

Query 深链（供 iframe / 书签）：

- `index.html?layout=landscape` 横屏标准
- `index.html?layout=portrait` 竖屏隐私

推荐 Chrome / Edge 最新版。断网可开，控制台应无任何错误。

## 三、目录结构

```
ver2/
├── index.html              # 唯一入口（工具栏 + 设备舞台 + 浮层根 + 按序加载脚本）
├── README.md               # 本文档
├── doc/                    # 规划文档（只读输入，未改动）
├── styles/
│   ├── tokens.css          # 设计令牌（色板/字号/间距/圆角/触控尺寸）
│   ├── base.css            # reset / 设备舞台 / 横竖外壳 / 页面骨架 / 工具栏
│   ├── components.css      # 通用组件（对应 js/core/ui.js 的 builder）
│   ├── cabin.css           # 状态侧舱 + CTX-01..08 + 竖屏底舱
│   ├── overlays.css        # OV-01..12 浮层
│   ├── gallery.css         # 页面总览缩略图墙
│   └── pages-<模块>.css     # 各页面模块独有布局（含竖屏窄主区覆盖）
└── js/
    ├── core/               # icons / ui / mode(横竖+隐私) / router / shell / cabin
    │                       # overlays / states / flows / gallery
    ├── data/mock-data.js   # 全量 mock 数据（演示"今天"= 2026-07-22）
    └── pages/pages-<模块>.js # 系统/首页/库存/对话/计划/更多 六个模块的页面注册与流程
```

架构约定：所有 JS 挂 `window.FS`；页面 = 注册表项 + `render(pg)` 渲染函数（返回 HTML 字符串，
与 LVGL"页面容器 + 子对象树"同构）；路由 `#/p/<页面ID>?参数`（file:// 安全、可刷新、可深链）；
侧导航切模块始终进入该模块一级页（不恢复上次子页现场）；侧舱是独立状态机，不随主页面重建。
布局模式 `FS.mode`：`landscape` / `portrait`；`portrait` 强制 `isPrivacy()===true`。

### 竖屏隐私规则（必须可见）

- 状态舱显示 **隐私模式** 芯片；健康区摄像头图标为 `off`。
- 拍照按钮改为「摄像头关」（禁用态），点击 toast 说明。
- 路由拦截 `INV-05` / `INV-06`；流程「拍照登记」不可启动。
- 横屏模式行为与原先完全一致（含拍照登记）。

## 七、LVGL 保真规范（本预览自查依据，固件实现对照）

1. 设备舞台内全部固定 px（与设备 1:1），外壳恒为 704/72/248 × 600，禁 vw/vh。
2. 布局只用 flex/grid → 对应 `LV_FLEX` / `LV_GRID`，无浮动/定位技巧。
3. 禁 backdrop-filter 与大面积模糊；遮罩 = 纯色 `rgba(36,52,45,.55)`（`lv_obj` + `bg_opa`）；
   阴影仅浮层小阴影（≤8px），固件以 1px 描边替代。
4. 圆角 ≤8px；字号仅 18/22/28/36/48/64 六档。
5. 动画仅 opacity/transform、≤200ms、可中断；无大面积循环动画。
   例外说明：OV-05 麦克风呼吸圈为预览表现，固件用静态帧或低频局部刷新；
   计时数字在预览中为静态 mock，固件用 `lv_timer` 1s 局部刷新。
6. 不依赖悬停：hover 仅是增强，所有操作有可见按钮；触控目标 ≥48px。
7. 图标 = 内联 SVG 单色（对应固件 TF 卡 PNG/字形资源），图标位均有文字标签可回退；
   图片一律 `.img-ph` 占位块（对应 TF 卡资源缺失回退策略）。
8. 滚动区统一 `.scroll-area`（= LVGL 可滚动容器），禁嵌套滚动。
9. 颜色纯色平铺、RGB565 友好；语义色克制为 ok/warn/danger/offline/info 五色。
10. 几何例外显式化：SYS 系统页隐藏侧导航（主区 776）、OV-10 全屏接管（P0）——
    对应固件 Page Manager 的特殊页类型。

## 八、与规划文档的对应解读（实现时做的一致化决定）

- **系统页侧舱简化**：规范要求"三部分始终同时存在；系统页面与关键告警除外"。本预览对
  SYS-01/02/03 隐藏 72px 侧导航，侧舱分别降级为 自检摘要 / 向导进度 / 仅时间温湿度。
- **INV-01 单模板**：3 层级 × 2 视图共用一个渲染函数，由 URL 参数（zone/layer/cell/view）驱动；
  页面总览中为 INV-01 出 5 张变体（根空间 / 分区空间 / 九宫格空间 / 根列表 / 分区列表）。
- **三级空间共用一套视觉语言**：L1 分区块 / L2 层卡 / L3 格子都按"范围内最差食材"上语义色
  （`ui.freshTone()` 直接复用 `dataQ.daysTone` 阈值：过期或今天到期=红 / 3 天内临期=黄 /
  都还富余=绿 / 空=灰），用户在任一层级都用同一套颜色判断"哪里要先处理"。
  L1/L2 是"语义浅底 + 左侧 4px 色条 + 大号项数"；L3 沿用 ver1 风格（见下条）。
- **L3 九宫格沿用 ver1 视觉**：一整块大圆角板用发丝线切成九格（不是九张独立卡片），
  每格自上而下 = 位置名·格号（内/中/外 × 左/中/右）/ 食材名 + 数量 / 整格宽到期条。
  每格严格只存放一项食材；点击已占用格直接进入该食材的 INV-03，点击空格直接进入已预填位置的 INV-04。
  L3 不套内胆卡头（层名已在页头副标题与面包屑里），整块高度让给九宫格以容下上述信息。
- **九宫格不做合并位**：L3 恒为 A1–C3 九个等大单位格。规划文档提到的"相邻格合并"在本版本
  被取消——合并会让位置模型、食材 `loc.cells` 与布局编辑都复杂一档，而收益只是一个自定义位名。
  因此 INV-08 只编辑"形状"（分区矩形 + 层）；第三级仅展示固定九宫格规则。
- **INV-08 按入口层级分成独立页**：从库存 L1、L2、L3 分别进入分区形状、指定分区层结构、指定层设置；
  不在编辑页内显示标签栏或分区芯片，返回始终回到进入前的位置。
  命名不强制走软键盘：常用名/类型做成预置芯片一点即改（仍保留 OV-12 键盘入口）。
- **删除前引导迁移而非拒绝**：分区/层里还有食材时，确认框直接给"去查看"，跳到该范围的库存
  列表（`INV-01?zone=..&view=list`），对应规范"保存前迁移受影响食材"。
- **INV-05 不开真实摄像头**：预览用静态取景框（隐私考虑 + file:// 限制），快门按钮触发
  "拍照登记"流程演示（INV-05 → OV-07 → INV-06 → 确认 → toast）。
- **识别结果不落库**：INV-06 的所有操作都止步于"确认/待确认/取消"的演示反馈，
  对应规范"识别结果需确认后才会写入库存"。
- **mock 数据**：演示"今天"锚定 2026-07-22（`js/data/mock-data.js` 的 `TODAY`），
