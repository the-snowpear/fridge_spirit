# 冰箱小精灵页面样式设计交接提示词 V1.0

你将根据配套规划文档，为“冰箱小精灵”设计完整页面样式与组件规范。不得修改规划文档中的页面数量、层级、导航、交互流程和模块职责。

## 技术前提

- 主控：**ESP32-P4**，ESP32-C6 负责无线通信协同。
- 屏幕：**1024×600 横屏触摸屏**。
- GUI：**LVGL**，不是网页、React、Flutter 或手机 App。
- 固定布局：**704 px 主交互区 + 72 px 侧边导航 + 248 px 状态侧舱**。
- 一级导航：**首页、库存、对话、计划、更多**。
- 状态侧舱：顶部时间/温湿度；设备健康采用紧凑图标；中部为大面积动态上下文；底部长期保留语音和拍照两个大按钮。

## 必须保持的业务结构

1. 30 个页面模板，ID 和用途以主规划文档与 JSON 清单为准。
2. 库存为三级空间：全冰箱分区 → 分区内分层 → 层内可选九宫格。
3. 一级分区首版默认用 3×3 可合并网格；第三级固定为 3×3 九宫格，一格只放一项食材，不支持合并。
4. 库存页顶部永久保留“空间视图 / 列表视图”切换；列表范围跟随当前空间路径。
5. 对话页必须展示 Agent 的工具调用、执行进度、确认和结果卡片。
6. 设备、设置、定时器、闹钟、安全、插件、日志和 OTA 全部放在“更多”。
7. 设计必须包含 Loading、Empty、Offline、Error、Pending confirmation 等状态。

## 输出要求

- 先输出统一组件体系和页面框架，再逐页设计 30 个页面模板。
- 每页注明页面 ID、页面标题、主要组件、可滚动区域、固定区域和关键交互状态。
- 对 INV-01 至少给出：根分区空间视图、分层空间视图、九宫格空间视图、根列表视图、分区列表视图五种状态。
- 对状态侧舱给出 8 种动态上下文状态。
- 所有设计必须能用 LVGL 常规对象实现，避免依赖复杂模糊、持续大面积动画或网页悬停交互。
