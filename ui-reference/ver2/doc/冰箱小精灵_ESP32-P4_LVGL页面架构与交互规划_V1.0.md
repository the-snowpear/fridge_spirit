# 冰箱小精灵 ESP32-P4 多模态 Agent 终端
## LVGL 页面架构与交互规划 V1.0

> 本文档只定义页面数量、页面层级、基础页面内容、交互逻辑、状态切换与 LVGL 实现约束；不规定最终视觉风格、配色、字体或动效语言。

## 1. 技术与产品基线

- 主控：**ESP32-P4**
- 无线协同：ESP32-C6（Wi-Fi / Bluetooth 通信协同）
- 屏幕：**1024 × 600 横屏**
- GUI 框架：**LVGL**
- 软件基础：ESP-IDF + FreeRTOS + LVGL
- 本地存储：TF 卡保存库存、任务、记忆、日志、插件与资源；关键配置进入 NVS/安全存储

### 固定屏幕结构

```text
┌────────────── 704 px 主交互区 ──────────────┬─72 px─┬── 248 px 状态侧舱 ──┐
│ 页面标题、内容、编辑、确认与业务流程          │ 首页  │ 时间/温湿度           │
│                                             │ 库存  │ 设备健康图标           │
│                                             │ 对话  │ 大型动态上下文区       │
│                                             │ 计划  │                      │
│                                             │ 更多  │ [语音]      [拍照]    │
└─────────────────────────────────────────────┴───────┴──────────────────────┘
```

一级导航固定为：**首页、库存、对话、计划、更多**。设备、设置、定时器、闹钟、安全、日志、插件和 OTA 均进入“更多”。

## 4. 全局框架与导航逻辑

- 主内容区、侧边导航、状态侧舱三部分始终同时存在；系统页和关键告警除外。
- 切换一级模块时，保存各模块最近页面、路径、筛选和滚动位置。
- 返回键顺序：关闭覆盖层 → 返回模块内上一级 → 回到模块根页。
- 状态侧舱的设备健康区只用紧凑图标；点击图标进入“设备与厨房安全”。
- 状态侧舱动态上下文区是主状态反馈区域；底部长期保留语音和拍照两个大按钮。
- Agent 可以请求切页，但不能在用户编辑、识别确认、烹饪步骤或关键告警时强制抢页。

## 5. 库存系统核心逻辑

### 5.1 三级空间结构

#### L1 全冰箱分区

默认采用 3×3 可合并网格建立冷藏、冷冻、门架、抽屉和自定义分区；支持多个相邻格合并形成不同大小和形状。

- 点击逻辑：点击分区进入 L2。
- 列表范围：切换列表后显示该分区的全部食材；在根层切换则显示全冰箱库存。

#### L2 分区内分层

每个分区可配置任意数量的层、抽屉或门架槽位，并支持自定义名称、排序和启停。

- 点击逻辑：若该层启用了九宫格，进入 L3；未启用时直接进入位置内食材。
- 列表范围：切换列表后只显示当前层的食材。

#### L3 具体九宫格位置（可选）

每层可启用 3×3 九宫格；相邻格可合并并命名。食材可定位到单格或连续合并位置。

- 点击逻辑：点击位置进入位置内食材。
- 列表范围：切换列表后只显示当前格子/合并位置中的食材。

### 5.2 位置精度

- 仅分区：冷藏区
- 分区 + 层：冷藏区 / 第 2 层
- 分区 + 层 + 位置：冷藏区 / 第 2 层 / B2+B3
- 位置未知/待补充

### 5.3 空间/列表切换

- 空间/列表切换按钮固定保留在库存浏览器顶部。
- 切换只改变显示方式，不改变当前路径、筛选范围和返回栈。
- 空间视图回答“放在哪里”，列表视图回答“有什么”。
- 从列表进入详情后返回，应恢复原列表的范围、筛选和滚动位置。

### 5.4 布局规则

- 合并只允许相邻格；首版建议限制为连续正交区域，禁止不相连位置合并。
- 删除含库存的分区、层或格子前，必须先迁移食材。
- 第三级九宫格不强制启用；高频快速登记允许只定位到 L1 或 L2。
- 布局修改先保存草稿，确认影响范围后一次提交。

## 6. 页面明细

### 系统

#### SYS-01 启动与自检

**定位：** 完成上电启动、关键外设检测和异常分流。

**入口：** 设备上电；OTA 重启；异常重启后恢复

**基础内容：**
- 品牌/项目标识与启动进度
- 屏幕、触摸、TF 卡、ESP32-C6、音频、摄像头、传感器自检结果
- 网络连接与本地数据恢复状态
- 异常项的可继续/需处理提示

**主要交互：**
- 正常完成后进入待机页或恢复上次页面
- 非关键外设失败时允许降级运行
- 关键存储或配置损坏时进入维护入口

**状态侧舱：** 启动阶段状态侧舱可简化为自检摘要，不显示语音和拍照按钮。

#### SYS-02 首次配网与设备绑定向导

**定位：** 完成首次使用必须的网络、家庭绑定、隐私和冰箱布局初始化。

**入口：** 首次启动；恢复出厂设置后；用户在设置中重新进入向导

**基础内容：**
- 步骤 1：设备说明与语言/时区
- 步骤 2：BLE/SoftAP 配网与云端绑定
- 步骤 3：语音、摄像头、图片保存和 Agent 权限说明
- 步骤 4：选择默认冰箱布局或创建自定义布局

**主要交互：**
- 逐步前进/返回
- 允许暂时跳过云端绑定并以离线模式使用
- 完成后进入首页

**状态侧舱：** 显示当前步骤、连接状态和帮助提示。

#### SYS-03 待机颜文字

**定位：** 在无人或长时间无操作时提供低信息密度、低打扰的陪伴与状态反馈。

**入口：** 毫米波判断无人；超时无操作；夜间低功耗前的过渡状态

**基础内容：**
- 颜文字/简单角色状态
- 时间与一句短提示
- 必要的临期、离线或提醒摘要

**主要交互：**
- 有人靠近后恢复到首页或上次页面
- 触摸、语音唤醒、开门事件立即退出待机
- 夜间满足条件后关闭背光

**状态侧舱：** 仅保留时间、温湿度和最小设备状态。

### 首页

#### HOME-01 首页

**定位：** 用一屏回答“今天冰箱有什么值得处理、可以吃什么、系统是否正常”。

**入口：** 侧边导航“首页”；有人靠近后的默认活跃页；退出任务流程后回到首页

**基础内容：**
- 库存总量与临期数量摘要
- 临期食材 Top 3
- 今日或本餐推荐
- 购物清单/菜单计划摘要
- Agent 主动建议与可执行动作
- 最近一次库存变化或同步结果

**主要交互：**
- 进入今日摘要详情
- 点击临期项进入食材详情
- 接受/忽略 Agent 建议
- 跳转到库存、计划或对话

**状态侧舱：** 显示今日摘要、下一项重要事件和设备当前状态。

#### HOME-02 今日摘要详情

**定位：** 集中查看当日临期、推荐、库存变化和计划执行情况。

**入口：** 首页点击“查看全部”；开门后点击完整提醒

**基础内容：**
- 临期/过期分组
- 今日推荐菜与原因
- 计划中缺失的食材
- 今日库存新增/消耗记录
- Agent 可执行建议

**主要交互：**
- 批量加入购物清单
- 生成菜谱
- 进入对应食材或计划
- 与 Agent 继续讨论

**状态侧舱：** 显示当前摘要范围和可立即执行的建议。

### 库存

#### INV-01 库存浏览器

**定位：** 同时承担空间视图和列表视图，并在不同空间范围中复用。

**入口：** 侧边导航“库存”；首页临期卡片；Agent 工具调用完成后定位到库存

**基础内容：**
- 固定的“空间视图 / 列表视图”切换
- 当前位置路径：冰箱 > 分区 > 层 > 格子
- 空间视图三级内容或当前范围的库存列表
- 搜索、筛选、排序、添加和布局管理入口
- 当前范围的总数、临期数、未定位数

**主要交互：**
- 空间视图逐级进入分区、层和格子
- 任何层级切换到相同范围的列表视图
- 列表项进入食材详情
- 添加、搜索、筛选和进入布局编辑

**状态侧舱：** 显示当前空间范围、食材统计、临期项和最近操作。

**特别规则：** 该模板对应 3 个空间层级 × 2 种视图，但只计为 1 个页面模板。

#### INV-03 食材详情

**定位：** 查看和处理一个库存批次的完整信息。

**入口：** 点击任意食材项；首页/对话/计划中的食材引用

**基础内容：**
- 名称、分类、数量和单位
- 登记时间、来源、置信度
- 生产/到期日期及“估算”标记
- 位置精度与完整路径
- 最近操作记录
- 推荐做法与关联菜谱

**主要交互：**
- 增加/消耗数量
- 编辑信息
- 移动位置
- 加入购物清单
- 删除或标记已用完

**状态侧舱：** 显示该食材剩余时间、位置和推荐动作。

#### INV-04 新增/编辑食材

**定位：** 完成手动新增、语音解析后的补充确认或已有食材编辑。

**入口：** 库存添加按钮；快速添加；语音登记结果；食材详情编辑

**基础内容：**
- 食材名称、分类、数量和单位
- 日期信息和估算开关
- 位置选择：分区/层/格子
- 备注、来源和合并批次选项

**主要交互：**
- 保存
- 保存并继续添加
- 选择位置
- 合并已有批次或创建新批次
- 取消并返回来源页

**状态侧舱：** 显示待保存字段摘要、当前位置建议和校验错误。

#### INV-05 拍照取景与拍摄

**定位：** 完成食材拍摄、照片确认和上传前检查。

**入口：** 状态侧舱拍照按钮；首页/库存添加中的拍照登记；语音“开始拍照”

**基础内容：**
- 摄像头预览或取景提示
- 拍摄按钮与重拍入口
- 补光/隐私提示
- 网络和上传可用状态

**主要交互：**
- 拍摄
- 重拍
- 使用照片并上传
- 取消并返回来源页

**状态侧舱：** 主要显示取景提示、摄像头状态和后续识别进度。

#### INV-06 识别结果确认

**定位：** 将视觉模型候选结果转换为可信库存记录，禁止识别后直接入库。

**入口：** 拍照识别返回结果；小程序远程识别待设备确认

**基础内容：**
- 候选食材列表及置信度
- 每项名称、数量、单位和日期
- 日期估算/低置信度警告
- 存放位置快速建议与空间地图入口
- 同名批次合并建议

**主要交互：**
- 勾选保留项
- 逐项修改
- 选择位置
- 确认入库并同步
- 保存为待确认
- 全部取消

**状态侧舱：** 显示识别任务状态、待确认项数量和风险提示。

#### INV-07 搜索与筛选结果

**定位：** 跨当前空间范围快速定位食材并执行批量操作。

**入口：** 库存搜索；点击临期/过期/未定位统计；语音查询结果

**基础内容：**
- 搜索词和当前空间范围
- 筛选：全部、临期、过期、未定位、不同类别
- 排序：到期、添加时间、名称、数量、位置
- 结果列表与批量选择

**主要交互：**
- 进入详情
- 批量移动
- 批量加入购物清单
- 清除筛选返回库存浏览器

**状态侧舱：** 显示结果数量、筛选条件和批量操作进度。

#### INV-08 冰箱布局管理

**定位：** 配置三级空间结构，同时保证已有库存不会因布局修改丢失。

**入口：** 库存浏览器“布局管理”；首次设置向导；设置中心的冰箱结构入口

**基础内容：**
- 一级分区编辑：默认 3×3 可合并网格
- 二级层管理：添加、命名、排序、删除层/抽屉/门架
- 三级位置编辑：每层可选 3×3 九宫格及相邻格合并
- 已有食材占用与待迁移提示

**主要交互：**
- 选择相邻格并合并/拆分
- 设置区域类型与名称
- 添加/重排层
- 启用或关闭某层九宫格
- 保存前迁移受影响食材

**状态侧舱：** 显示当前编辑层级、未保存修改和受影响食材数量。

**特别规则：** 第三级九宫格为可选精确定位；食材允许只记录到分区或层。

### 对话

#### CHAT-01 对话主页面

**定位：** 承载连续对话、工具调用和可执行结果，是 Agent 的主要可视界面。

**入口：** 侧边导航“对话”；语音复杂请求；其他页面“与 Agent 继续”

**基础内容：**
- 用户与 Agent 消息流
- 工具调用卡片及状态
- 结果卡片：库存、菜谱、购物清单、任务等
- 输入区和常用指令
- 当前权限模式与会话状态

**主要交互：**
- 文本/语音输入
- 停止生成或播报
- 确认/拒绝工具动作
- 点击结果跳转业务页
- 查看执行详情和会话历史

**状态侧舱：** 大面积显示聆听、理解、规划、执行和完成状态。

#### CHAT-02 会话历史

**定位：** 查看、恢复、重命名和清理历史会话。

**入口：** 对话页会话入口

**基础内容：**
- 会话列表
- 时间、摘要、关联任务和同步状态
- 搜索与过滤

**主要交互：**
- 打开会话
- 新建会话
- 重命名
- 删除/归档
- 继续同步会话

**状态侧舱：** 显示当前选择会话的摘要和同步情况。

#### CHAT-03 工具执行详情

**定位：** 让用户理解 Agent 实际执行了什么、为何执行以及执行结果。

**入口：** 点击对话中的工具调用卡片；日志中的 Agent 调用记录

**基础内容：**
- 工具名称、风险等级和权限判断
- 结构化参数摘要
- 执行时间线
- 结果、错误与重试信息
- 关联业务对象和操作日志

**主要交互：**
- 重试
- 撤销可撤销动作
- 打开结果页
- 复制诊断信息

**状态侧舱：** 显示当前工具状态、失败原因和下一步。

#### CHAT-04 待确认行动

**定位：** 集中处理 Agent 一次计划中的一个或多个需确认动作。

**入口：** 确认模式下的写入/删除/上传/控制动作；标准模式中的高风险动作

**基础内容：**
- 计划摘要
- 动作列表及风险等级
- 将修改的数据对象
- 可选执行范围和不可逆提示

**主要交互：**
- 全部确认
- 逐项确认
- 修改参数
- 拒绝

- **CTX-03 语音：** 聆听状态；实时转写；取消/提交提示

## 8. 全局覆盖层

- **OV-01 轻提示 Toast**：保存成功、同步完成、普通错误等短反馈。（非阻塞）
- **OV-02 顶部/区域通知条**：离线、同步中、临期提醒等可持续但不阻断的状态。（非阻塞）
- **OV-03 通用确认框**：删除、取消编辑、清空筛选等普通确认。（阻塞）
- **OV-04 Agent 高风险操作确认**：删除、批量覆盖、上传、远程控制和敏感写入。（阻塞）
- **OV-05 语音聆听与转写层**：显示聆听、转写、取消和提交。（非阻塞）
- **OV-06 Agent 处理状态层**：显示理解、规划、工具执行和可中止状态。（非阻塞）
- **OV-07 拍照上传与识别进度**：显示上传、识别、失败重试和等待确认。（非阻塞）
- **OV-08 同步/离线状态层**：显示本地可用、待补传数量和重连。（非阻塞）
- **OV-09 定时器/闹钟到时层**：结束、延长一分钟、稍后提醒。（非阻塞）
- **OV-10 关键安全告警**：燃气、烟雾、严重硬件异常；允许抢占页面。（阻塞）
- **OV-11 快速添加面板**：选择拍照、语音或手动登记。（非阻塞）
- **OV-12 软键盘/数值与日期选择器**：文本、数量、日期和时间输入。（阻塞）

## 9. 关键业务流程

### 拍照登记食材

流程：

1. 任意页面点击状态侧舱“拍照”
2. INV-05 取景与拍摄
3. 上传并显示 OV-07 进度
4. INV-06 识别结果确认
5. 选择/修改位置
6. 确认写入本地库存
7. 异步同步云端和小程序
8. 返回来源页或打开新增结果

异常与限制：
- 离线时允许保存拍照任务状态；是否保留原图按实际存储策略提示
- 低置信度、日期估算和同名批次必须明确标记
- 用户取消时不写入库存

### 语音登记食材

流程：

1. 点击语音按钮或唤醒
2. OV-05 聆听与转写
3. 本地/云端解析名称、数量和日期
4. 进入 INV-04 补充确认
5. 选择位置或保留为待定位
6. 保存并同步

异常与限制：
- “停止、取消、返回”等短命令优先本地处理
- 不确定字段必须让用户确认

### Agent 执行库存/计划动作

流程：

1. CHAT-01 接收需求
2. 展示计划与工具调用卡片
3. Tool Broker 判断权限
4. 低风险自动执行或进入 CHAT-04 确认
5. 执行后展示结果卡片
6. 点击结果跳转业务页

异常与限制：
- Agent 不得在用户编辑、识别确认、关键告警时强制切页
- 删除、清空、批量覆盖等始终需要确认或更高权限

### 库存空间与列表切换

流程：

1. 进入 INV-01
2. 选择分区/层/格子形成当前 scope
3. 点击“列表”查看同一 scope 的库存
4. 筛选或打开食材详情
5. 返回恢复原 scope 与滚动位置
6. 点击“空间”恢复原空间层级

异常与限制：
- 搜索结果可暂时覆盖列表，但退出搜索后恢复原 scope
- 未配置九宫格的层不产生空的 L3 页面

### 烹饪与定时器

流程：

1. PLAN-04 菜谱详情开始烹饪
2. PLAN-05 单步模式
3. 需要计时时创建 MORE-02 定时器
4. 计时在状态侧舱常驻
5. 到时显示 OV-09
6. 完成后按确认量回写库存

异常与限制：
- 定时器到时不应丢失当前步骤
- 安全告警优先于烹饪页面

## 10. 页面抢占优先级

| 优先级 | 事件 | 处理方式 |
|---|---|---|
| P0 | 关键安全告警 | 全屏/强制层；持续播报；处理完成前不自动关闭。 |
| P1 | 高风险 Agent 确认、数据迁移确认 | 阻塞当前动作，但保留页面上下文。 |
| P2 | 定时器/闹钟到时 | 通知层 + 状态侧舱；除关键场景外不强制跳页。 |
| P3 | 用户主动触摸、语音、拍照 | 进入对应任务流程，可随时取消。 |
| P4 | 开门/靠近事件 | 空闲时更新主内容；编辑、确认、烹饪时只更新状态侧舱。 |
| P5 | 同步、临期和普通建议 | 非阻塞通知，不抢占页面。 |
| P6 | 待机与自动回首页 | 仅在无活动任务和无未保存内容时执行。 |

## 11. LVGL 实现交接约束

- 本项目不是网页或手机 App：目标硬件为 ESP32-P4，固定横屏 1024×600，界面框架为 LVGL。
- 全局 Shell 常驻：704 px 主内容区 + 72 px 侧边导航 + 248 px 状态侧舱；高度均为 600 px。
- 侧边导航固定为：首页、库存、对话、计划、更多。模块切换应保留各模块最近一次页面状态。
- 主内容区通过 Page Manager 切换 LVGL 页面容器；页面按需创建，离开重资源页面时销毁或回收。
- 状态侧舱为独立状态机，不随主页面整体重建；设备健康采用紧凑图标，动态上下文占主要高度，底部长期保留语音和拍照两个大按钮。
- 库存浏览器 INV-01 必须设计为数据驱动的可复用模板，而不是为每个分区/层创建不同页面。
- 异步任务必须有 loading、success、error、offline、retry 和 pending-confirmation 状态，不能假设网络立即返回。
- 交互不依赖鼠标悬停、右键或复杂手势；重要操作使用可见按钮。触控目标建议不小于 44–48 px。
- 不使用浏览器 CSS、DOM 或重型透明模糊作为实现前提；动画应短、可中断，避免大面积持续刷新。
- 图片、字体、图标和大资源应支持从 TF 卡加载；页面设计需允许资源缺失时显示占位内容。

## 12. 验收检查

- 30 个页面模板均有唯一 ID、入口、基础内容、主要动作和退出路径。
- 库存页顶部始终保留空间/列表切换；切换不丢失当前 scope。
- 一级分区、二级分层、三级九宫格的数据关系可配置；三级为可选。
- 语音、拍照、Agent 工具、同步和计时均有异步状态与失败处理。
- 所有低频功能位于“更多”，一级导航不增加新项目。
- 设计结果可直接映射为固定 1024×600 的 LVGL 页面，而不是网页响应式稿。
