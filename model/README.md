# 整机结构件与 3D 模型

「冰箱小精灵」的机械结构资料。可编辑源文件 + 可直接切片的 STL，按版本分目录。

| 目录 | 对应硬件 | 状态 |
| --- | --- | --- |
| `ver3/` | ESP32-P4 CB V1.2 + 7 英寸 MIPI-DSI 屏（当前主线） | 正在使用 |
| `legacy/` | ESP32-S3-DevKitC-1 + TR230S 4 英寸方屏（已归档） | 仅历史参考 |

## ver3 / 当前整机

| 文件 | 类型 | 作用 |

## 使用说明

- 单位一律为 **毫米**，按 1:1 导入切片软件，不要额外缩放。
- `.SLDPRT / .SLDASM` 需要 SolidWorks 或免费的 eDrawings 查看；**装配体必须与四个零件保持同目录**，移动文件会导致引用断开。
- `.STL` 是导出网格，不含公差补偿。不同打印机的收缩率与喷嘴间隙不同，首件建议先打小件验证配合，再打箱体。
- 屏幕件与箱体的配合面、螺丝柱孔径直接决定装配手感，改动前请对照实机复测。
- 结构与固件的版本对应关系记录在 `doc/progress.md`；`ver3` 对应 P4 主线（7 英寸 1024×600 屏）。

## 关于复用

结构件随仓库一并公开，供学习与复现参考。二次修改或量产前，请自行复核孔径、壁厚、螺丝规格与整机重心，并做好电气绝缘与散热评估。
